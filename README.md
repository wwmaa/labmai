 Программа "In-Memory Database"
Данная программа представляет собой объектно-ориентированную базу данных, которая работает полностью в оперативной памяти компьютера. Она позволяет пользователю работать с информацией о книгах: добавлять новые книги, просматривать все добавленные книги, искать нужные книги по названию, автору, году издания или жанру, а также изменять и удалять существующие записи. Программа разработана с использованием принципов объектно-ориентированного программирования и покрыта автоматическими тестами.

Структура проекта: pioa-m70-113bv-25/src/db/backend/errors.py - пользовательские исключения, pioa-m70-113bv-25/src/db/backend/memory.py - класс BookTable, pioa-m70-113bv-25/src/db/main.py - точка входа, pioa-m70-113bv-25/src/db/tui.py - пользовательский интерфейс, pioa-m70-113bv-25/tests/test_memory.py - тесты для класса BookTable, pioa-m70-113bv-25/README.md - документация.

Программа поддерживает следующие операции: добавление книги (создание новой записи с автоматическим ID), просмотр всех книг (вывод всех записей из таблицы), поиск с фильтрацией (по названию, автору, году, жанру), обновление книги (изменение существующей записи по ID) и удаление книги (удаление записи с подтверждением).

Программа построена вокруг класса BookTable, который содержит следующие методы: create_record() для добавления новой книги, select_record() для поиска книг с фильтрацией, update_record() для обновления информации о книге, delete_record() для удаления книги, get_all_records() для получения всех записей и get_record_count() для получения количества записей.

Для обработки ошибок созданы собственные классы исключений: InvalidYearError (возникает при попытке добавить книгу с некорректным годом), DuplicateIDError (возникает при попытке добавить книгу с уже существующим ID) и RecordNotFoundError (возникает при попытке обновить или удалить несуществующую запись).

Программа покрыта автоматическими тестами с использованием фреймворка unittest. Для запуска тестов используется команда python -m unittest discover tests. Для проверки покрытия кода тестами используется библиотека coverage. Команды для установки и запуска: pip install coverage, затем coverage run -m unittest discover tests, затем coverage report -m. Результат тестирования: 19 тестов пройдено успешно за 0.002 секунды.

Для работы программы требуется Python версии 3.6 или выше.
