 Программа "In-Memory Database"

## Описание программы

Данная программа представляет собой объектно-ориентированную базу данных, которая работает полностью в оперативной памяти компьютера. Она позволяет пользователю работать с информацией о книгах: добавлять новые книги, просматривать все добавленные книги, искать нужные книги по названию, автору, году издания или жанру, а также изменять и удалять существующие записи. Программа разработана с использованием принципов объектно-ориентированного программирования и покрыта автоматическими тестами.

## Функциональность проекта

Программа поддерживает следующие операции: добавление книги (создание новой записи с ID, указанным пользователем), просмотр всех книг (вывод всех записей из таблицы), поиск с фильтрацией (по названию, автору, году, жанру), обновление книги (изменение существующей записи по ID) и удаление книги (удаление записи с подтверждением).

## Объектно-ориентированная реализация

Программа построена вокруг класса BookTable, который содержит следующие методы: create_record() для добавления новой книги, select_record() для поиска книг с фильтрацией, update_record() для обновления информации о книге, delete_record() для удаления книги, get_all_records() для получения всех записей, get_record_count() для получения количества записей и get_record_by_id() для поиска записи по ID.

## Пользовательские исключения

Для обработки ошибок созданы собственные классы исключений: InvalidYearError (возникает при попытке добавить или обновить книгу с некорректным годом), DuplicateIDError (возникает при попытке добавить книгу с уже существующим ID) и RecordNotFoundError (возникает при попытке обновить или удалить несуществующую запись).

## Тестирование

Программа покрыта автоматическими тестами с использованием фреймворка unittest. Для запуска тестов используется команда python -m unittest discover tests. Для проверки покрытия кода тестами используется библиотека coverage. Команды для установки и запуска: pip install coverage, затем coverage run -m unittest discover tests, затем coverage report -m. Результат тестирования: 19 тестов пройдено успешно.
