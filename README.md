 ## Описание программы "In-Memory Database"

Данная программа представляет собой простую базу данных, которая работает полностью в оперативной памяти компьютера. Она позволяет пользователю работать с информацией о книгах: добавлять новые книги, просматривать все добавленные книги, искать нужные книги по названию, автору, году издания или жанру, а также изменять и удалять существующие записи.

При запуске программы пользователь видит текстовое меню с семью пунктами. Для начала работы в программе уже создана демонстрационная таблица под названием "books", которая готова к заполнению данными. Каждая книга имеет уникальный идентификатор (ID), который присваивается автоматически, а также название, автора, год издания и жанр.

Пользователь может добавить новую книгу, выбрав пункт меню 1. Программа запросит название, автора, год издания и жанр, после чего новая книга появится в таблице. Чтобы посмотреть все книги, нужно выбрать пункт 2 - программа покажет список всех сохранённых книг с их ID и остальными данными.

Функция поиска (пункт 3) позволяет найти книги, соответствующие заданным условиям. Пользователь может указать название, автора, год или жанр, а может пропустить ненужные поля. Например, можно найти все книги определённого автора или все книги, изданные в конкретном году. Если ничего не указывать, программа покажет все книги.

Функция обновления (пункт 4) позволяет изменить данные о книге. Пользователь вводит ID книги, которую хочет изменить, затем программа показывает текущие данные и запрашивает новые. Если какое-то поле не нужно менять, можно просто нажать Enter, и оно останется прежним.

Функция удаления (пункт 5) работает похожим образом. Пользователь вводит ID книги, подтверждает удаление, и книга исчезает из базы данных.

Также программа позволяет создать новую таблицу (пункт 6) и посмотреть список всех существующих таблиц (пункт 7).

Важной особенностью программы является обработка ошибок. Если пользователь введёт буквы вместо года, программа не сломается, а выведет сообщение "Ошибка: введите число!" и предложит ввести данные заново. Если оставить пустыми название или автора, программа сообщит, что поле не может быть пустым. Если указать несуществующий ID при обновлении или удалении, программа напишет, что книга не найдена. Все ошибки обрабатываются корректно, программа никогда не завершается аварийно.

Интерфейс программы полностью текстовый и работает через консоль. Пользователь выбирает нужное действие, вводя цифру от 0 до 7. Выход из программы осуществляется по команде 0.

Для запуска программы требуется Python версии 3.6 или выше. Чтобы запустить программу, нужно открыть командную строку, перейти в папку с проектом командой cd C:\Users\ASUS\pioa-m7o-113bv-25 (путь нужно указать свой), затем ввести команду python -m src.db и нажать Enter.
