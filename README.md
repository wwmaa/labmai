# Программа "In-Memory Database" с поддержкой файлового хранения

## Описание программы

Данная программа представляет собой базу данных, которая может работать в двух режимах: in-memory (данные хранятся только в оперативной памяти) и файловая СУБД (данные сохраняются на диск в формате JSON). Программа позволяет пользователю работать с информацией о книгах: добавлять новые книги, просматривать все добавленные книги, искать нужные книги по названию, автору, году издания или жанру, а также изменять и удалять существующие записи. Программа разработана с использованием принципов объектно-ориентированного программирования и покрыта автоматическими тестами.

## Функциональность проекта

Программа поддерживает следующие операции: создание таблицы, добавление книги (создание новой записи), просмотр всех книг (вывод всех записей из таблицы), поиск с фильтрацией (по любому полю), обновление книги (изменение существующей записи) и удаление книги (удаление записи). При запуске программы пользователь может выбрать тип базы данных: in-memory (данные не сохраняются после закрытия) или файловая (данные сохраняются в папке data в формате JSON).

## Различия между in-memory и файловой реализациями

In-memory версия (MemoryDatabase) хранит все таблицы и записи в оперативной памяти. При закрытии программы все данные теряются. Этот режим полезен для тестирования и быстрой работы. Файловая версия (FileDatabase) сохраняет каждую таблицу в отдельный JSON-файл в папке data. При следующем запуске программы данные автоматически загружаются из файлов. Это позволяет не терять информацию между сеансами работы.

## Объектно-ориентированная архитектура

Программа построена на следующих классах: Table (отвечает за структуру таблицы и операции с записями), Database (абстрактный базовый класс, задающий единый интерфейс), MemoryDatabase (реализация хранения в памяти), FileDatabase (реализация хранения в JSON-файлах). Такой подход позволяет легко добавлять новые способы хранения данных без изменения пользовательского интерфейса.

## Пользовательские исключения

Для обработки ошибок созданы собственные классы исключений: DatabaseError (базовый класс), TableAlreadyExistsError (таблица уже существует), TableNotFoundError (таблица не найдена), MissingColumnError (отсутствует обязательное поле), UnknownColumnError (неизвестное поле), InvalidStorageDataError (повреждённый файл таблицы).

## Тестирование

Программа покрыта автоматическими тестами с использованием фреймворка unittest. Тесты проверяют как in-memory реализацию, так и файловую. Для файловой реализации используется временная папка, чтобы не засорять основной каталог. Для запуска тестов используется команда python -m unittest discover tests. Для проверки покрытия кода тестами используется библиотека coverage. Команды для установки и запуска: pip install coverage, затем coverage run -m unittest discover tests, затем coverage report -m.

## Требования для запуска

Для работы программы требуется Python версии 3.10 или выше.

## Инструкция для запуска

Через командную строку: перейдите в папку проекта, затем выполните python -m src.db. В PyCharm: откройте проект, найдите файл src/db/__main__.py, нажмите правой кнопкой мыши и выберите Run '__main__'. При запуске программа попросит выбрать тип базы данных: введите 1 для in-memory или 2 для файловой.
